# Video course

A narrated walkthrough of this repository in **18 chapters**, built from code. **Every terminal in the video shows real
output**: the kubeadm, Minikube and MicroK8s lessons and the troubleshooting labs were recorded while CI ran them on
fresh virtual machines (`tests/mdrun.py --record`), and the EKS lesson while it ran against AWS. The AWS Console
screens are the real console, recorded in a read-only session during the same EKS run. Nothing on screen is typed by hand.

| # | Chapter | # | Chapter |
|---|---|---|---|
| 1 | Introduction | 10 | MicroK8s installation |
| 2 | What Kubernetes is | 11 | MicroK8s verification |
| 3 | Kubernetes architecture | 12 | Amazon EKS setup (incl. the console: what to click) |

## Two final versions

| File | Picture | Sound |
|---|---|---|
| `out/kubernetes-from-zero-full.mp4` | the edited video | narration (cleaned up), original background music ducked under the voice, subtle sound effects; -14 LUFS, true peak below -1 dBTP |
| `out/kubernetes-from-zero-silent.mp4` | **the identical picture stream** (copied from the same encode with `-c:v copy`, so cuts, transitions, animations, zooms and text match frame for frame) | none (no audio track) |

Production touches, each with a purpose: an animated title card and end card, section titles and a chapter progress
bar, elements that ease in as they are explained, **terminal zooms** that move the camera onto the lines being
explained (and back), highlighted lines in code, short fades between scenes, a whoosh on each cut (stronger on chapter
changes), an error tone when something breaks on screen and a chime when it is fixed or proven.

All music and sound effects are original and generated by code. [AUDIO-LICENSES.md](AUDIO-LICENSES.md) lists every
audio asset with its creator, source, license, attribution, and the timestamps where it plays (written by the build
from the real timeline).

## Files

| File | What it is |
|---|---|
| `scenes.py` | collects the chapters and adds the production layer (title card, end card, sound cues) |
| `scenes_1_intro.py` … `scenes_5_finish.py` | the script: scenes, narration steps and the visuals for each step |
| `scenes_common.py` | `S()` (a narration step, optional terminal zoom), `scene()`, the lesson file names |
| `recordings.py` + `recordings/` | the recorded commands and outputs, and `rec()` to show them in a scene |
| `components.py` | building blocks: cards, tiles, diagrams, highlighted code, terminals |
| `build.py` | page → frames (with ease-in frames) → narration → encode → captions, chapters, description → post-production |
| `production.py` | title card, end card and the sound-effect cues |
| `audio_assets.py` | the original music bed and sound effects (synthesised; `python video/audio_assets.py preview` writes samples) |
| `redact.py` | removes identifying data from everything that reaches the video; the build fails if any remains |
| `shot.mjs` | screenshots every frame with one headless Edge/Chrome (no extensions, no sync) |
| `tts.ps1` | narration with the Windows speech engine (`System.Speech`) |
| `thumbnail.html` | the YouTube thumbnail (1280×720) |
| `youtube/` | upload package: title, description with chapters, tags, captions (SRT), thumbnail, pinned comment |

## Build

Requirements: Windows (for `System.Speech`), Python 3 with `pygments`, `numpy` and `scipy`, Node.js 22+, Microsoft Edge
(or set `BROWSER`), and Docker (ffmpeg runs in a container pinned by digest).

```text
gh run download <run-id> -D rec-ci                    # the run-kubeadm, run-minikube, run-microk8s artifacts
python video/recordings.py rec-ci/* rec-eks           # copy the recordings the video uses into video/recordings/
python video/build.py                                 # → video/out/kubernetes-from-zero-full.mp4 and -silent.mp4
```

`python video/build.py page` writes only the HTML page (open `out/page.html?sc=12&st=1` to see scene 12, step 1).
